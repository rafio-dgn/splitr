# Todos

Live state of the work. Keep it honest — an item marked done that is not done is
worse than no tracker.

| File | Purpose |
|---|---|
| [`backlog.md`](./backlog.md) | Blockers, open questions, queued work, stretch items |

## Conventions

- `- [ ]` open, `- [x]` done, `- [~]` in progress, `- [!]` blocked.
- Tag items: `blocker`, `stretch`, `question`, `tech-debt`.
- Link the requirement id once `../requirements/` is populated.
- Closing an item is a change — it gets a `CHANGELOG.md` entry like anything else.
- Move an item to `../requirements/` the moment it turns out to be a real
  requirement rather than an idea.
